# Médias des pubs Tadaa

Dépôt technique. Il ne contient que les vidéos des publicités de l'application
Tadaa, servies par GitHub Pages pour que l'outil de programmation des
publications puisse les récupérer par une URL.

Aucun code, aucune donnée. Les vidéos sont de toute façon destinées à être
publiées sur les réseaux.
